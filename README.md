# Game Picker

Dont know which game to play? Try out Game Picker.

## Description

Game Picker randomly suggests you a game if you dont know which game to play. You can select Competitive or Story game and the website will randomly select a game from that category. If you didnt like the game, you can click try again for another suggestion.
